# Exemplos para testar

Três textos de teste, do jeito que um modelo escreve em português. Cada um foi montado com
padrões conhecidos, listados embaixo — dá para conferir se a skill pegou todos.

Para usar:

```text
/escrita-humana isso tem cara de IA? (cole o texto de um dos arquivos)
```

Depois peça a edição e compare com a lista.

| Arquivo | Formato | Padrões plantados |
| --- | --- | --- |
| `post-linkedin.md` | post | pergunta retórica de abertura, contraste binário, falso insight, fragmentação dramática, ritmo robótico, pedido de engajamento, emoji em título, frase de efeito no fim |
| `newsletter.md` | newsletter | pigarro de abertura, revelação com dois-pontos, pergunta autorrespondida, análise superficial de gerúndio, atribuição vaga, rodízio de sinônimos, fecho-resumo, travessão decorativo |
| `email-interno.md` | email de trabalho | formalidade postiça, gerundismo, verbo forte de mentira, inflação de importância, metadiscurso, conectivo no piloto automático, decalque do inglês |

O que a skill **não** pode fazer com eles: inventar número que não está lá, tirar a opinião forte,
uniformizar os três no mesmo tom.
